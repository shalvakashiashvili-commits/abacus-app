# აბაკუსი — სორობანის და ანძანის სასწავლო PWA

სუფთა HTML + CSS + JavaScript (ES მოდულები), ფრეიმვორკების, build-ის და გარე ბიბლიოთეკების გარეშე.
მუშაობს სრულად offline-ში, ყენდება ტელეფონის მთავარ ეკრანზე. **ეტაპი 1:** აპლიკაციის ჩარჩო + PWA + დონეები 0–4.

## სტრუქტურა

```
index.html            აპლიკაციის გარსი
manifest.json         PWA მანიფესტი („აბაკუსი“, standalone, portrait, ხატულები)
sw.js                 service worker (ქეშის ვერსია: CACHE_VERSION)
css/style.css         დიზაინი, ღია/მუქი თემა
js/soroban.js         სორობანის მოდელი (მძივები ↔ რიცხვი)
js/soroban-view.js    ვირტუალური სორობანი ეკრანზე (შეხება, ანიმაცია, ტურის განათება)
js/techniques.js      ფორმულების ძრავა: მოქმედება → ფორმულა → ნაბიჯები და წარწერები
js/generator.js       მაგალითების გენერატორი (მხოლოდ ნასწავლი ფორმულებით)
js/levels.js          ყველა დონის კონფიგურაცია (ერთ ობიექტში)
js/lessons.js         გაკვეთილების ტექსტები და დემოები
js/progress.js        პროგრესი localStorage-ში, ექსპორტი/იმპორტი
js/lesson-player.js   ახსნის ეკრანი (ბარათები, ნაბიჯ-ნაბიჯ დემო, ტური)
js/exercise.js        სავარჯიშოები (წაკითხვა, ჩაწერა, გამოთვლა, სვეტური ჯამი), ტესტი, შედეგები
js/app.js             მარშრუტიზაცია და ეკრანები
icons/                ხატულები (192, 512, maskable)
tests/run-tests.js    ტესტები (Node)
tools/make-icons.mjs  ხატულების გენერატორი (Node)
```

`tests/`, `tools/`, `package.json` და `.claude/` მხოლოდ დეველოპმენტისთვისაა; GitHub Pages-ზე ხელს არ უშლის.

## ტესტების გაშვება

```
node tests/run-tests.js
```

თუ Node დაყენებული არ არის, VS Code-ის ჩაშენებული Node-იც გამოდგება (PowerShell):

```powershell
$env:ELECTRON_RUN_AS_NODE = '1'; & "$env:LOCALAPPDATA\Programs\Microsoft VS Code\Code.exe" tests/run-tests.js | Out-String
```

## GitHub Pages-ზე განთავსება (ახალი repository)

1. GitHub-ზე: **New repository** → სახელი `abacus-app` → **Public** → README-ის გარეშე → **Create repository**.
2. ფაილების ატვირთვა — ერთ-ერთი გზით:
   - **ბრაუზერით:** repository-ის გვერდზე **„uploading an existing file“** → `abacus-app` საქაღალდის **შიგთავსი** (არა თავად საქაღალდე) გადაათრიე → **Commit changes**. `index.html` repository-ის ძირში უნდა აღმოჩნდეს.
   - **git-ით** (`abacus-app` საქაღალდეში):
     ```
     git init
     git add .
     git commit -m "აბაკუსი: ეტაპი 1"
     git branch -M main
     git remote add origin https://github.com/USERNAME/abacus-app.git
     git push -u origin main
     ```
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, საქაღალდე **/ (root)** → **Save**.
4. 1–2 წუთში აპლიკაცია გაიხსნება: `https://USERNAME.github.io/abacus-app/`
   (ყველა მისამართი ფარდობითია `./`, ამიტომ ქვემისამართზე სწორად მუშაობს).

## ტელეფონზე დაყენება და offline-ის შემოწმება

1. Android-ზე გახსენი **Chrome** → `https://USERNAME.github.io/abacus-app/`.
2. დაელოდე გვერდის სრულ ჩატვირთვას (ამ დროს ყველა ფაილი ქეშირდება).
3. მენიუ **⋮** → **„მთავარ ეკრანზე დამატება“** (ან „აპის დაყენება“) → **დამატება**.
4. გახსენი აპლიკაცია მთავარი ეკრანის ხატულიდან — ის ბრაუზერის ზოლის გარეშე, ცალკე აპად გაიხსნება.
5. **Offline შემოწმება:** ჩართე ავიარეჟიმი → დახურე აპი (ბოლო აპების სიიდანაც) → ხელახლა გახსენი. ყველაფერი უნდა მუშაობდეს: გაკვეთილები, სავარჯიშოები, პროგრესი.
   **პარამეტრები → აპლიკაცია**-ში ჩანს ქეშის ვერსია (`abacus-v1`).

პროგრესი ინახება ტელეფონზე. ტელეფონის შეცვლამდე: **პარამეტრები → ექსპორტი (JSON)**, ახალ ტელეფონზე — **იმპორტი**.

## განახლება შემდეგ ეტაპებზე

1. შეცვალე/დაამატე ფაილები. ახალი ფაილი აუცილებლად ჩაწერე `sw.js`-ის `ASSETS` სიაში (ტესტი ამას ამოწმებს).
2. `sw.js`-ში გაზარდე ვერსია: `const CACHE_VERSION = 'abacus-v2';` (შემდეგ `v3` და ა.შ.).
3. გაუშვი ტესტები, შემდეგ ატვირთე GitHub-ზე (commit/push).
4. ტელეფონზე აპი ახალ ვერსიას შემდეგი გახსნისას იპოვის (ინტერნეტით): ფონურად ჩამოტვირთავს ახალ ფაილებს, ძველ ქეშს წაშლის და გამოჩნდება შეტყობინება **„აპლიკაცია განახლდა — გადატვირთვა“**. თუ არ გამოჩნდა: **პარამეტრები → განახლების შემოწმება**, ან აპი დახურე და ხელახლა გახსენი. პროგრესი განახლებისას არ იკარგება.

GitHub Pages ფაილებს ~10 წუთით აქეშებს, ამიტომ ატვირთვიდან რამდენიმე წუთში შეიძლება ჯერ ძველი ვერსია ჩანდეს.
